# Code for phason-induced IQC nucleation pathways

This repository contains the custom MPI/C++ code used to compute critical nuclei
and transition pathways for the manuscript

**"Phason-induced nucleation pathways of thermodynamically degenerate
icosahedral quasicrystals"**.

The code implements a Fourier pseudo-spectral discretization of the Landau free
energy model described in the manuscript, together with gradient descent,
LOBPCG-based Hessian eigenmode calculations, and the Spring Pair Method (SPM)
for locating index-1 saddle points. The principal target system in the submitted
configuration is a three-dimensional icosahedral-quasicrystal (IQC) calculation
with periodic approximation length `L = 26` and grid size `N = 256`.

## Essential user configuration

Before compiling or running on a new system, please check the following items.
These are the only system-dependent settings expected to require user changes.

1. **Compiler and library paths.** Edit or override the MPI, FFTW, and Eigen
   paths in `makefile` and `makefile1` if they differ from the submitted cluster
   paths:

   ```make
   /beegfs/software/mpich/mpich-4.0.3
   /beegfs/software/fftw/fftw-3.3.10
   /beegfs/software/eigen/include
   ```

   For example:

   ```bash
   make MPI_ROOT=/path/to/mpi FFTW_ROOT=/path/to/fftw EIGEN_ROOT=/path/to/eigen/include
   ```

2. **Runtime library path.** Set `LD_LIBRARY_PATH` so the executable can find
   MPI, FFTW, and the local libraries in `./lib`.

3. **MPI task count.** The submitted setup uses `N = 256` and the example scripts
   use 32 MPI tasks. Use a task count that divides 256, because the current data
   distribution assumes an even split along the first grid dimension.

4. **SLURM settings.** If using `job_spm.sh` or `job_grad.sh`, edit the partition,
   node count, and task count as needed for the local cluster. The scripts run
   `./spm_yzys` for `main_SPM.cpp` and `./grad_yzys` for `grad.cpp`.

5. **Two-stage workflow.** Run `main_SPM.cpp` first to generate `result/S1.txt`.
   Then compile and run `grad.cpp` to relax from that saddle point. The two
   stages are intentionally built with separate makefiles: `makefile` for
   `./spm_yzys` and `makefile1` for `./grad_yzys`.

## Repository contents

```text
.
├── main_SPM.cpp          Main program for computing a saddle point / critical nucleus
├── grad.cpp              Main program for relaxing from the saddle along an unstable mode
├── makefile              Build file for spm_yzys, the first-stage executable
├── makefile1             Build file for grad_yzys, the second-stage executable
├── job_spm.sh            Example SLURM script for running main_SPM.cpp
├── job_grad.sh           Example SLURM script for running the gradient-relaxation stage
├── include/              Header files
├── src/                  Source files for numerical kernels and algorithms
├── initData/             Fourier-mode initial data for ordered phases
├── result/               Post-processing script and generated output files
└── log/                  Runtime log directory created by the job scripts
```

The `result/` directory may contain only post-processing scripts in a fresh
source-only archive. The main output files
are generated by the two-stage workflow described below.

## Numerical model

The code solves the Landau free-energy model

```text
F[phi] = 1/2 ∫∫ phi(r) V(|r-r'|) phi(r') dr dr'
       + ∫ [ epsilon/2 phi^2 - alpha/3 phi^3 + 1/4 phi^4 ] dr
```

using a Fourier pseudo-spectral method. In the current source code, the model
parameters are set in `src/Initialization.cpp`:

```cpp
N     = 256;
L     = 26;
Tau   = -0.0061;
Gamma = 0.30;
dt    = 0.3;
```

The code variable `Tau` is the coefficient used in the implemented free-energy
and gradient formulas. The manuscript denotes the temperature-like quadratic
control parameter by `epsilon`; the sign convention in the implementation should
be read directly from `src/LPsrc.cpp`.

The pair-interaction kernel in Fourier space is evaluated by `get_GK()` in
`src/Initialization.cpp`.

## Main algorithms

- `main_SPM.cpp`: computes a metastable/minimum state, evaluates low Hessian
  eigenmodes using LOBPCG, initializes two SPM replicas with a small perturbation
  along an eigenmode, and runs SPM to obtain a saddle point / critical nucleus.
  If the LOBPCG iteration loop in `main_SPM.cpp` is disabled, the same line uses
  the random direction generated by `hiosd_lobpcg_initialization()` instead.
- `grad.cpp`: loads the saddle point from `result/S1.txt`, computes or loads
  Hessian eigenmodes at the saddle, perturbs the saddle along the first unstable
  direction, and relaxes by gradient descent to a neighboring minimum.
- `src/LPsrc.cpp`: energy evaluation, gradient descent, and negative-gradient
  computation.
- `src/SPM.cpp`: Spring Pair Method update, natural-force step, and min-max
  force step.
- `src/LOBPCG.cpp`: Hessian-vector product, preconditioner, and LOBPCG
  eigensolver.
- `src/My_FFT.cpp`: MPI-enabled FFTW wrappers and FFTW wisdom handling.
- `src/File_Op.cpp`: ASCII input/output for density fields and eigenvectors.

## Requirements

The code was written for a Linux high-performance-computing environment with:

- MPI compiler wrapper, tested with MPICH
- FFTW3 with MPI support
- Eigen3
- A POSIX shell environment
- SLURM, if using the provided job scripts

For visualization with `result/plotphi.py`, Python with NumPy, SciPy, and Mayavi
is required. Visualization is optional and is not needed for the MPI calculation.

## Build

Minimal workflow:

```bash
# 1. Build and run the saddle-point search.
make
mpirun -np 32 ./spm_yzys

# 2. After result/S1.txt has been generated, build and run the second stage.
make -f makefile1
mpirun -np 32 ./grad_yzys

# 3. Optional visualization.
python result/plotphi.py result/S1.txt
python result/plotphi.py result/Min.txt
```

To build the first-stage executable from `main_SPM.cpp`, run:

```bash
make
```

This creates:

```text
./spm_yzys
```

After `./spm_yzys` has finished and `result/S1.txt` exists, build the second-stage
executable from `grad.cpp`:

```bash
make -f makefile1
```

This creates:

```text
./grad_yzys
```

If the compiler, FFTW, or Eigen installation differs from the paths above, use the
corresponding local paths in both `makefile` and `makefile1`, or override
`MPI_ROOT`, `FFTW_ROOT`, and `EIGEN_ROOT` on the `make` command line.

## Runtime environment

Before running, make sure the dynamic linker can find FFTW, MPI, and the local
shared libraries:

```bash
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/path/to/fftw/lib:/path/to/mpi/lib:$PWD/lib
```

For the submitted parameter set `N = 256`, runs are memory-intensive. The example
SLURM scripts request 32 MPI tasks on one node. The current MPI scatter/gather
layout assumes that the first grid dimension is evenly distributed across MPI
tasks; using a task count that divides `N = 256` is recommended.

The wall-clock time depends strongly on the MPI process count, FFTW planning,
hardware, and convergence behavior. On a typical HPC node, the submitted
`N = 256` runs should be treated as production calculations rather than quick
desktop tests.

## Running the calculation

### 1. Saddle-point / critical-nucleus search

Build the first-stage executable:

```bash
make
```

Run with MPI:

```bash
mpirun -np 32 ./spm_yzys
```

or submit the example SLURM script:

```bash
sbatch job_spm.sh
```

This stage performs the following operations:

1. sets model and discretization parameters;
2. initializes the density field from `initData/DIS`;
3. relaxes to a minimum using gradient descent;
4. computes low Hessian eigenmodes by LOBPCG;
5. initializes the Spring Pair Method using a small eigenmode perturbation;
6. saves the resulting saddle-point density field.

By default, the SPM perturbation is

```cpp
Phi0[1] = u_R_local + 0.001 * option1->V[0]
```

where `option1->V[0]` is the first LOBPCG-computed Hessian eigenvector. If the
LOBPCG iteration loop in `main_SPM.cpp` is commented out, `option1->V[0]`
remains the random mean-zero direction produced during initialization, so the SPM
search is initialized by a random perturbation instead.

Expected primary output:

```text
result/S1.txt
```

`S1.txt` contains one real-space density value per line, ordered on the
`N x N x N` grid.

### 2. Downhill relaxation from the saddle

After `result/S1.txt` has been generated, run:

```bash
make -f makefile1
mpirun -np 32 ./grad_yzys
```

This stage:

1. loads `result/S1.txt`;
2. computes Hessian eigenmodes at the saddle, unless `result/V1_saddle.txt`
   already exists;
3. perturbs the saddle along the first eigenmode;
4. relaxes the perturbed field to a neighboring minimum;
5. saves the relaxed minimum and its eigenvectors.

Expected primary outputs:

```text
result/Min.txt
result/V1_saddle.txt
result/V0_Min.txt
```

## Input files

Files in `initData/` define Fourier-mode initial conditions. The first line is the
number of modes. Each following line contains integer wave-index components and a
coefficient:

```text
k1  k2  k3  amplitude
```

The active initial phase is selected by `Ini_Phase` in `src/Initialization.cpp`.
In the submitted `main_SPM.cpp` workflow, `Ini_Phase = 0`, which selects
`initData/DIS`.

## Output file format

Density fields and eigenvectors are stored as plain ASCII text. Each line contains
the real part of one grid value. Complex arrays are used internally for FFTW, but
the physical density fields are real-valued in these output files.

Important outputs:

- `result/S1.txt`: saddle point / critical nucleus found by SPM.
- `result/Min.txt`: relaxed minimum obtained from the saddle perturbation.
- `result/V1_saddle.txt`: Hessian eigenvectors at the saddle.
- `result/V0_Min.txt`: Hessian eigenvectors at the relaxed minimum.
- `log/*.log`: runtime logs generated by the SLURM job scripts.

## Visualization

The script `result/plotphi.py` provides a Mayavi-based example for visualizing a
three-dimensional density field and its Fourier-space peaks. It can load the ASCII
`.txt` files written by the C++ code directly:

```bash
python result/plotphi.py result/S1.txt
python result/plotphi.py result/Min.txt
```

MATLAB `.mat` files are also supported:

```bash
python result/plotphi.py result/S1.mat --mat-key x1
```

The script is included as a post-processing example rather than as part of the
core MPI workflow.

Additional visualization and structural analysis used in the manuscript, including
particle extraction, symmetry metrics, and OVITO rendering, were performed in
separate post-processing workflows.

## Notes for reproducibility

- The code uses FFTW wisdom. If no matching wisdom file is found, FFTW creates new
  plans and writes a file such as `fftw_wisdom_3d_N256.dat`.
- The calculations are deterministic after the generated LOBPCG initial vectors are
  fixed by the executable and process layout, but small numerical differences may
  occur across MPI/FFTW versions and process counts.
- The default grid size `N = 256` and domain parameter `L = 26` correspond to the
  periodic-approximation setting described in the Methods section of the
  manuscript.
- If running `grad.cpp`, generate `result/S1.txt` first using `main_SPM.cpp`;
  then build `grad_yzys` with `make -f makefile1`. The gradient-relaxation
  program expects `result/S1.txt` to exist.
